# 📊 حسابدار فروش | مدیریت سفارش‌ها و سود (باسلام + سایت فروشگاهی)

برنامه حسابداری حرفه‌ای، فارسی و راست‌چین برای فروش **واسطه‌ای** (دراپشیپینگ) با پشتیبانی از:
- 🛍 **باسلام** با **چند غرفه**
- 🌐 **سایت فروشگاهی**
- 📅 **تقویم و تاریخ شمسی** در همه‌جا
- 📈 تحلیل سود و زیان **روزانه / هفتگی / ماهانه / سالانه** با نمودارهای جذاب
- 🧾 صدور فاکتور، خروجی اکسل، بکاپ JSON
- ☁️ اجرا روی **Cloudflare Workers** + دیتابیس **D1**

## ✨ امکانات

| بخش | توضیح |
|---|---|
| داشبورد | فروش، هزینه، سود خالص، حاشیه سود، میانگین سبد، روند فروش/سود، سهم منابع، عملکرد غرفه‌ها، پرفروش‌ترین کالاها، آخرین سفارش‌ها |
| ثبت سفارش | نام مشتری، تلفن، شهر، کالا، تعداد، تامین‌کننده، قیمت فروش، هزینه خرید، تخفیف، ارسال، بسته‌بندی، کمیسیون، تبلیغات، سایر هزینه‌ها، وضعیت سفارش و پرداخت، تاریخ شمسی، **محاسبه لحظه‌ای سود** |
| گزارش و تحلیل | سود و زیان دوره‌ای (روزانه/هفتگی/ماهانه/سالانه)، عملکرد تامین‌کنندگان، تحلیل کالاها + نمودار |
| غرفه‌ها | مدیریت چند غرفه باسلام با آمار فروش و سود هر غرفه |
| تامین‌کنندگان | مدیریت واسطه‌ها با آمار خرید و سود |
| فاکتور | نمایش و چاپ فاکتور فروش برای هر سفارش |
| داده | خروجی اکسل (CSV)، بکاپ/بازیابی JSON، داده نمونه برای تست |

## 🚀 اجرای سریع (۵ دقیقه‌ای)

### روش ۱: با دیتابیس دائمی D1 (پیشنهادی)

```bash
npm install
npx wrangler login
npx wrangler d1 create hesabdar-db
# خروجی database_id را در wrangler.toml جای‌گذاری و بخش d1_databases را از کامنت خارج کنید
npm run deploy
# آدرس https://hesabdar-foroosh.<your-subdomain>.workers.dev آماده است ✅
```

> جدول‌ها به‌صورت خودکار ساخته می‌شوند؛ نیازی به اجرای دستی `schema.sql` نیست (ولی اگر خواستید: `npm run db:init`).

### روش ۲: تست سریع بدون دیتابیس

```bash
npm install
npm run dev
# مرورگر: http://localhost:8787
```

در این حالت داده‌ها در حافظه موقت ورکر است. اگر حتی ورکر هم بالا نباشد، برنامه خودش به **حالت محلی (localStorage مرورگر)** می‌رود و کامل کار می‌کند.

## 🗂 ساختار پروژه

```
├── src/
│   ├── frontend.html   # کل رابط کاربری (تک‌فایل، فارسی، شمسی، نمودارها)
│   └── worker.js       # بک‌اند ورکر + API + سرو فرانت‌اند
├── build.js            # تزریق فرانت‌اند داخل ورکر → dist/worker.js
├── wrangler.toml       # تنظیمات Cloudflare
├── schema.sql          # اسکیمای D1 (اختیاری، برای ساخت دستی)
└── package.json        # اسکریپت‌های build / dev / deploy
```

## 🧮 فرمول سود

```
فروش = قیمت فروش واحد × تعداد − تخفیف
هزینه = (هزینه خرید واحد × تعداد) + ارسال + بسته‌بندی + کمیسیون + تبلیغات + سایر
سود = فروش − هزینه
```

- سفارش **لغو شده**: در آمار لحاظ نمی‌شود.
- سفارش **مرجوعی**: فروش صفر و هزینه‌ها به‌عنوان زیان لحاظ می‌شود (قابل تغییر در داشبورد).
