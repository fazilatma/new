# 📊 حسابدار فروش | مدیریت سفارش‌ها و سود (باسلام + سایت فروشگاهی)

برنامه حسابداری حرفه‌ای، فارسی و راست‌چین برای فروش **واسطه‌ای** (دراپشیپینگ) با پشتیبانی از:
- 🛍 **باسلام** با **چند غرفه**
- 🌐 **سایت فروشگاهی**
- 📅 **تقویم و تاریخ شمسی** در همه‌جا
- 📈 تحلیل سود و زیان **روزانه / هفتگی / ماهانه / سالانه** با نمودارهای جذاب
- 🧾 صدور فاکتور، خروجی اکسل، بکاپ JSON
- ☁️ اجرا روی **Cloudflare Workers** + دیتابیس **D1**

## 🔗 اتصال خودکار (باسلام + ووکامرس)

از بخش **«اتصال‌ها»** در برنامه:

| اتصال | چه چیزی لازم است | از کجا بگیرید |
|---|---|---|
| 🛍 غرفه باسلام (هر غرفه جداگانه) | Personal Access Token با دسترسی `vendor.parcel.read` | [پنل توسعه‌دهندگان باسلام](https://developers.basalam.com/panel/tokens) |
| 🌐 سایت ووکامرس | آدرس سایت + Consumer Key + Consumer Secret با دسترسی Read | پیشخوان وردپرس ← ووکامرس ← تنظیمات ← پیشرفته ← REST API |

- دکمه **«تست اتصال»** صحت توکن/کلید را بررسی می‌کند و اسم غرفه یا فروشگاه را نشان می‌دهد.
- دکمه **«سینک سفارش‌ها»** سفارش‌های N روز اخیر را وارد حسابداری می‌کند (کد `BL-…` برای باسلام و `WC-…` برای سایت).
- سینک مجدد **تکراری ایجاد نمی‌کند** و **هزینه‌ها/تامین‌کننده‌ای که دستی ثبت کرده‌اید را پاک نمی‌کند** (فقط اطلاعات فروش و وضعیت به‌روز می‌شود).
- 🔐 توکن‌ها و رمزها فقط در دیتابیس خصوصی شما (D1) ذخیره می‌شوند و هیچ‌وقت به مرورگر ارسال نمی‌شوند.
- ⏰ **سینک خودکار ساعتی:** کافی است در کارت اتصال تیک «خودکار» را بزنید — ورکر هر ساعت سفارش‌های ۲ روز اخیر همه اتصال‌های خودکار را سینک می‌کند. (اگر با روش «کپی‌پیست در داشبورد» دیپلوی کرده‌اید، یک‌بار در داشبورد اضافه کنید: ورکر ← Settings ← Triggers ← Cron Triggers ← Add با عبارت `0 * * * *`)
- 🔄 دکمه **«سینک همه اتصال‌ها»** همه منابع (باسلام + سایت‌ها) را یکجا سینک می‌کند.

## 🚀 اجرا و دیپلوی

### روش صفر: اتصال گیت‌هاب به کلاودفلر (پیشنهادی 🤖) — بدون سکرت، بدون توکن

فقط چند کلیک، فقط یک‌بار. بعد از آن هر Push به‌صورت خودکار دیپلوی می‌شود و هر دیپلوی یک **ورژن** جدید در داشبورد می‌سازد:

1. در داشبورد Cloudflare: **Workers & Pages ← Create ← Connect to Git** ← انتخاب همین ریپو:
   - Production branch: همان شاخه‌ای که کد نهایی در آن است
   - Build command: `npm run build` (بقیه پیش‌فرض) ← **Deploy**
2. ساخت دیتابیس: **Storage & databases ← D1 SQL Databases ← Create** با نام `hesabdar-db`
3. اتصال دیتابیس: لازم نیست! ✅ اتصال دیتابیس داخل کد ثبت شده و با هر دیپلوی خودکار اعمال می‌شود. (اگر قبلاً دستی binding اضافه کرده‌اید، می‌توانید حذفش کنید — اختیاری.)
4. تمام! 🎉 از این به بعد هر Push = یک ورژن جدید، خودکار.

> در صفحه ورکر، تب **Versions** تاریخچه همه ورژن‌ها را نشان می‌دهد و با **Rollback** می‌توانید با یک کلیک به هر ورژن قبلی برگردید.

### روش ۱: دستی با CLI

```bash
npm install
npx wrangler login
npx wrangler login
# (دیتابیس از قبل ساخته شده و اتصال آن داخل wrangler.toml ثبت است)
npm run deploy
# آدرس https://hesabdar.<your-subdomain>.workers.dev آماده است ✅
```

> جدول‌ها به‌صورت خودکار ساخته می‌شوند.

### روش ۲: فقط با داشبورد (بدون ترمینال)

1. دیپلوی کد با روش کپی‌پیست (Edit code).
2. ساخت دیتابیس: **Storage & databases ← D1 SQL Databases ← Create** با نام `hesabdar-db`.
3. اتصال: داخل ورکر ← **Settings ← Bindings ← Add ← D1 database** با نام متغیر `DB` ← انتخاب دیتابیس ← Save و Deploy مجدد.

### تست محلی

```bash
npm install
npm run dev
# مرورگر: http://localhost:8787
```

> ⚠️ دیتابیس **D1 الزامی** است و هیچ حالت موقت/محلی وجود ندارد. در `wrangler dev` دیتابیس به‌صورت محلی شبیه‌سازی می‌شود. اگر از نسخه‌های قبلی داده‌ای در مرورگر دارید، برنامه خودش پیشنهاد «انتقال به فضای دائمی» می‌دهد.

## ☁️ بکاپ ابری خودکار (گوگل درایو / وان‌درایو)

علاوه بر D1، برنامه هر روز یک بکاپ کامل در فضای ابری **خودتان** ذخیره می‌کند. راه‌اندازی (یک‌بار):

**گوگل درایو:**
1. در [console.cloud.google.com](https://console.cloud.google.com) پروژه بسازید و **Google Drive API** را Enable کنید.
2. در **OAuth consent screen** نوع External را کامل کنید و ایمیل خودتان را در Test users اضافه کنید.
3. در **Credentials ← OAuth client ID** نوع Web بسازید و Redirect URI نمایش‌داده‌شده در برنامه (تنظیمات ← بکاپ ابری) را ثبت کنید.
4. Client ID و Secret را در برنامه ذخیره و «اتصال حساب» را بزنید.

**وان‌درایو:**
1. در [portal.azure.com](https://portal.azure.com) مسیر **Microsoft Entra ID ← App registrations ← New registration** با Redirect URI برنامه.
2. مقدار **Application (client) ID** و یک **Client secret** بسازید و در برنامه ذخیره کنید.
3. «اتصال حساب» را بزنید. (مجوز لازم: `Files.ReadWrite`)

بعد از اتصال: بکاپ روزانه خودکار (همراه Cron ساعتی) + دکمه «بکاپ فوری» + بازیابی از لیست فایل‌ها.

## 🧮 فرمول سود

```
فروش = قیمت فروش واحد × تعداد − تخفیف
هزینه = (هزینه خرید واحد × تعداد) + ارسال + بسته‌بندی + کمیسیون + تبلیغات + سایر
سود = فروش − هزینه
```

- سفارش **لغو شده**: در آمار لحاظ نمی‌شود.
- سفارش **مرجوعی**: فروش صفر و هزینه‌ها به‌عنوان زیان لحاظ می‌شود (قابل تغییر در داشبورد).
