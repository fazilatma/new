# برنامهٔ وفاداری کامل Scraper 4 PHP → Render TypeScript

مبنای بازبینی: `scraper4.php` نسخه 9.80، کل فایل ۳۶٬۲۰۰ خطی — نه فقط منوی همبرگری.

> اصلاح گزارش قبلی: عدد ۵۷ فقط inventory عملیات اصلی منوی همبرگری بود و به معنی برابری کل برنامه نبود. ممیزی خودکار جدید در `scripts/parity-audit.mjs` تمام شرط‌های GET، actionهای POST، Routeهای TypeScript و actionهای رابط را استخراج می‌کند. خروجی آخر در `parity-audit.json` ذخیره می‌شود.

آخرین ممیزی خام: ۱۵۰ شرط GET و ۲۸ action POST در PHP، در برابر ۵۷ Route و ۴۲ action رابط در TypeScript. بخشی از GETهای PHP پارامتر هستند، بااین‌حال اختلاف نشان می‌دهد هنوز سازگاری کامل حاصل نشده است.

## ترتیب تحویل انتخاب‌شده

1. **فاز ۱ — زیرساخت و مهاجرت:** منو، Vault، PostgreSQL، صف، پروفایل، استخراج، انتقال settings و اتصال‌های کامل.
2. **فاز ۲ — ارتباطات (انجام شد):** AI چندارائه‌دهنده، رأی مدل، اعلان‌های بله/روبیکا، چندغرفه باسلام و مسیرهای شبکه.
3. **فاز ۳ — نگهداری مقصد (انجام شد):** retirement، recon، bulk editor، photo-fix و remote-map rebuild.
4. **فاز ۴ — اتوماسیون (انجام شد):** یادگیری دسته، پاسخ خودکار، گزارش شبانه، سفارش‌ها و گفتگوها.
5. **فاز ۵ — تطبیق منوی همبرگری (انجام شد):** inventory ۵۷ عملیات اصلی، خودآزمون runtime و تست build.
6. **فاز ۶ — ممیزی کل فایل (در حال انجام):** همه GET/POSTها، import/export، مدیریت صف‌ها، دسته‌ها و APIهای مدیریتی مقصد.
7. **فاز ۷ — سازگاری پیشرفته:** stream/SSE، گزارش‌های ریز، تغییر وضعیت‌های باسلام، duplicate/fix-category و ابزارهای AI محصول.
8. **فاز ۸ — آزمون با fixture واقعی:** مقایسه پاسخ PHP و TypeScript روی داده و حساب آزمایشی.

## نتیجهٔ تطبیق منوی همبرگری (نه کل برنامه)

- ۵۷ عملیات منوی PHP شناسه یکتا و وضعیت قابل ماشین‌خواندن دارند (`render-src/parity.ts`).
- عملیات مخرب فقط با `APPLY` و ارسال گزارش فقط با `SEND` اجرا می‌شوند.
- `/api/selftest` اتصال دیتابیس، جداول، خزانه و تعداد قابلیت‌ها را در محیط واقعی بررسی می‌کند.
- `/api/parity` گزارش کامل قابلیت‌ها را برای رابط برمی‌گرداند.
- دو مورد عمداً **account-dependent** هستند: اتصال غیرمستقیم همه endpointهای باسلام و مسیر شبکه مبدأ. عملکرد آن‌ها به نوع Proxy و مجوز API حساب بستگی دارد.
- نصب نسخه کد و rollback به امکانات Deploy خود Render نگاشت شده و اجرای فایل‌محور PHP را تقلید نمی‌کند.

هیچ گزینه‌ای که فقط ظاهر داشته باشد «کامل» علامت نخورده است؛ موارد account-dependent در API و رابط صریحاً مشخص‌اند.
