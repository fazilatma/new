🌐 شبکه و آزمایش مبدأ — اتصال srcNetCfg / srcNetTest

برای اسنپ‌شاپ، دیجی‌کالا و باسلام فقط API مبدأ استفاده می‌شود؛ حتی با انتخاب Jina/CSS/Selenium/Playwright مسیر مؤثر همین API است؛ بنابراین «آزمایش همهٔ موتورها» چند مسیر مستقل شبکه را امتحان نمی‌کند. محصولات قدیمی استخراج‌شده با Jina اثبات اتصال API فعلی نیستند. تنظیم renderer راه‌حل خطای اتصال این APIها نیست. درخواست شبکه می‌تواند به علت پراکسی میزبان، TLS، DNS یا timeout شکست بخورد. این پنل نتیجهٔ واقعی یک صفحه را بدون تغییر محصولات/صف نشان می‌دهد.



پراکسی آماده یا راه دورزدن شبکه به‌صورت خودکار ساخته نمی‌شود؛ TLS معتبر باقی می‌ماند. DNS-pinning، relay worker، SOCKS و inherit-AI در این اتصال هنوز پیاده نشده‌اند. تنظیم این بخش در بکاپ تنظیمات نسخهٔ فعلی قرار نمی‌گیرد. این تنظیم فقط انتقال مبدأ را تغییر می‌دهد، نه شبکهٔ ارسال مقصد.
