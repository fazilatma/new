اتصال PythonAnywhere

نصب و ورود به پنل به توکن API نیاز ندارد. برای اتوآپدیت، توکن حساب PythonAnywhere را اینجا وارد کنید؛ این توکن با کلید API خود برنامه متفاوت است.

ابتدا ذخیره، سپس تست و فعال‌سازی را بزنید. فعال‌سازی فقط Task همین برنامه را می‌سازد یا به‌روزرسانی می‌کند و فایل WSGI سایت دیگری را تغییر نمی‌دهد. محدودیت‌های API و پلن حساب همچنان برقرارند.
