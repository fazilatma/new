گزارش امن، بدون اشتراک رمز پنل

این گزارش فقط تنظیمات پایه و وضعیت محلی صفِ پروفایل انتخاب‌شده را می‌خواند؛ مبدأ را آزمایش یا استخراج را اجرا نمی‌کند. URL مبدأ، کوکی، CSRF، رمز، کلید اتصال و متن خام خطا داخل گزارش نیستند. نام پروفایل و وضعیت کارها داخل فایل هستند؛ پیش از ارسال فایل، محتوایش را بازبینی کنید.

دانلود فایل JSON برای ارسال در گفتگو

این فایل، کلید دسترسی به پنل نیست؛ فقط یک snapshot از اطلاعات نمایش‌داده‌شده است. برای بررسی توسط عامل، فایل دانلودشده را در گفتگو پیوست کنید؛ پسورد یا توکن نفرستید.

فهرست منبع و قراردادهای متصل

فهرست کامل ارجاع‌های ثابت GET/POST/REQUEST منبع PHP منتقل شده است. این فهرست شامل فیلدهای فرم هم هست و اثبات پیاده‌سازی تمام endpointها نیست. فقط قراردادهایی که صریحاً متصل‌اند قابل اجرا هستند؛ ناشناخته‌ها 501 می‌گیرند.
