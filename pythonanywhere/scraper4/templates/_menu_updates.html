مدیریت خودکار و به‌روزرسانی

پس از ذخیرهٔ توکن و فعال‌سازی Task در بخش بالا، Task به‌صورت دوره‌ای نسخه را بررسی، پشتیبان تهیه و برنامه را Reload می‌کند. درخواست‌های این بخش هم با همان Task اجرا می‌شوند، نه داخل وب.

تا زمانی که توکن ذخیره و Task فعال نشده باشد، آپدیت و ثبت Reload در صف Task اجرا نمی‌شوند؛ نصب و ورود به پنل مستقل از توکن است.

استقرار خودکار عامل پس از push
عامل یک نسخهٔ مشخص از همین شاخه را با امضای دیجیتال تأیید و اندپوینت استقرار را فراخوانی می‌کند؛ توکن PythonAnywhere از سرور خارج نمی‌شود. تغییرات صرفاً کد و رابط بدون Task نصب می‌شوند؛ تغییر وابستگی‌ها یا کد دیتابیس به نصبگر CLI نیاز دارد.
آدرس /api/deploy/run بدون سند امضاشده هیچ آپدیتی اجرا نمی‌کند. دریافت موفق درخواست به معنی فعال‌شدن نسخه نیست؛ نسخه و commit زنده باید در /healthz تطبیق داده شوند.
کلید API برای اتوماسیون
کلید API دسترسی کامل مدیر دارد؛ فقط یک‌بار نمایش داده می‌شود. برای فهرست اندپوینت‌ها از /api/endpoints استفاده کنید.
