📂 پروفایل‌ها

تغییرات فقط با «ذخیره» یا شروع استخراج روی همین پروفایل اعمال می‌شود؛ برای آدرس تازه از «جدید» یا «کپی تنظیمات» استفاده کنید.

یک فایل عمومی تا ۱ مگابایت / ۱۰۰۰ محصول؛ CSV با UTF-8 یا اولین برگهٔ XLSX بدون فرمول. سرستون‌های title یا name، price، link، image، sku؛ گالری با images. ارسال شناسهٔ مقصد از فایل مجاز نیست. مخزن خصوصی و XLS قدیمی پشتیبانی نمی‌شوند.

🔗 آدرس و محدوده

۰ = تشخیص خودکار پایان؛ توقف در صفحهٔ خالی، آخرین صفحه یا تکرار نتایج. سقف ایمنی ۱۰۰۰ صفحه است، نه استخراج بی‌نهایت. برای GitHub محدودهٔ صفحات کاربرد ندارد.

آدرس دیجی‌کالا / باسلام موتور API متناظر را پیشنهاد می‌دهد؛ موتور را می‌توانید دستی تغییر دهید. موتورهای مرورگر به سرویس رندر بیرونی نیاز دارند.






  
🔍 استخراج جزئیات

  
  
جزئیات فقط با سلکتورهای فعال جزئیات اجرا می‌شود. هر مرحله حداکثر یک صفحهٔ فهرست یا یک محصول است؛ قیمت‌ها، شناسه‌های مقصد و گالری غنی‌تر حفظ می‌شوند. GitHub جزئیات را از ستون‌های همان فایل وارد می‌کند.







  

  

  

  
ذخیره و صف‌سازی در همین صفحه انجام می‌شود. ادامه با کران خارجیِ فعال شما یا worker است؛ بستن مرورگر صف بک‌اند را متوقف نمی‌کند. «دستی» ویرایش CSS را باز می‌کند؛ انتخاب بصری کلیکیِ PHP هنوز موجود نیست.

  
🔄 همگام‌سازی دستی — استخراج ← جزئیات ← صف ارسال
فقط پس از پایان موفق و غیرخالیِ استخراج، ارسال تمام محصولات ذخیره‌شدهٔ همین پروفایل، از جمله محصولات قبلی به مقصدهای انتخابی صف می‌شود. هیچ ارسالی در این درخواست انجام نمی‌شود؛ کران/worker ادامه می‌دهد. قبل از تلاش دوبارهٔ ارسال ناموفق، مقصد را بررسی کنید.
تنظیمات عنوان، قیمت و دستهٔ همین پروفایل را در تب تنظیمات ذخیره کنید. قبل از تأیید ارسال، پیش‌نمایش قیمت و خروجی را بررسی کنید؛ همهٔ فیلترها و رسانه‌های PHP هنوز کامل منتقل نشده‌اند.
تنوع‌ها / همهٔ فیلدهای ارسال PHP و گزارش پیام‌رسان هنوز کامل منتقل نشده‌اند. اگر مقصد انتخاب نکنید، زنجیره شروع نمی‌شود.





  
📊 نمای تفصیلی کل محصولات
همهٔ پروفایل‌های ذخیره‌شده؛ برای جزئیات شاخص روی کارت بزنید.

  
در حال محاسبهٔ آمار…
«آمادهٔ پایهٔ ارسال» فقط یعنی قیمت + تصویر + لینک؛ تضمین اعتبارسنجی مقصد نیست. موجودی فقط از فیلد صریح منبع است، نه موجودی زندهٔ مقصد؛ شاخص‌ها هم‌پوشان‌اند.




📋 تفکیک پروفایل‌ها و پوشش جزئیات
بزرگ‌ترین پروفایل‌ها در بالا
ستون‌های مقصد فقط تعداد محصولات دارای شناسهٔ ذخیره‌شدهٔ همان مقصد/غرفه‌اند؛ نه شمار موجودی واقعی، نه اختلاف قیمت زنده. محصول ارسال‌شده به دو غرفه در هر دو شمرده می‌شود. تطبیق کامل موجودی و اختلاف قیمت PHP هنوز آماده نیست.


📈 روند تعداد نگاشت‌های غرفه‌ها
تاریخچهٔ مشترک و پایدارِ مجموع شناسه‌های محلی باسلام، از اولین ثبت نمودار. این نمودار موجودی زندهٔ غرفه نیست. حداقل فاصلهٔ ثبت یک دقیقه؛ نگهداری تا ۷۲۰ به‌روزرسانی / ۱۸۰ روز، بدون ساختن روزهای گذشته.


📋 کپی تنظیمات پروفایل
سلکتورها، جزئیات و تنظیمات کپی می‌شوند. محصولات و شناسه‌های مقصد کپی نمی‌شوند تا ناخواسته برای دو پروفایل ارسال نشوند.
