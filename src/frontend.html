☁️ بکاپ ابری خودکار (گوگل درایو / وان‌درایو)

علاوه بر دیتابیس دائمی، هر روز یک نسخه پشتیبان کامل در فضای ابری خودتان ذخیره می‌شود. هر لحظه هم می‌توانید بکاپ فوری بگیرید یا بازیابی کنید.

▾ ❓ راهنمای ساخت Client ID و Secret
گوگل درایو:
۱. وارد console.cloud.google.com ↗ شوید ← پروژه جدید بسازید ← از Library عبارت Google Drive API را Enable کنید.
۲. از منوی APIs & Services ← OAuth consent screen ← نوع External ← نام و ایمیل را وارد کنید ← در بخش Test users ایمیل خودتان را اضافه کنید.
۳. از Credentials ← Create Credentials ← OAuth client ID ← نوع Web application ← در قسمت Authorized redirect URIs همان Redirect URI بالای همین کارت را وارد کنید ← Create.
۴. Client ID و Client Secret را اینجا ذخیره کنید و «اتصال حساب» را بزنید.

وان‌درایو (مایکروسافت):
۱. وارد portal.azure.com ↗ شوید ← Microsoft Entra ID ← App registrations ← New registration ← نام دلخواه ← گزینه حساب‌های شخصی و سازمانی ← Redirect URI از نوع Web با همان آدرس بالای کارت ← Register.
۲. مقدار Application (client) ID را اینجا ذخیره کنید.
۳. از Certificates & secrets ← New client secret ← مقدار Value را کپی و اینجا ذخیره کنید.
۴. «اتصال حساب» را بزنید و با حساب مایکروسافت تایید کنید. (مجوز لازم: Files.ReadWrite)
