# فونت‌های فارسی

بخش «تنظیمات عمومی → فونت کل سایت» این فونت‌ها را ارائه می‌کند:
وزیر، یکان، شبنم، ساحل، صمیم.

## چطور کار می‌کند

`/assets/fonts/<name>.css` یک استایل‌شیت `@font-face` برمی‌گرداند:

* اگر فایل `<name>.woff2` **در همین پوشه** باشد، از روی سرور خودتان سرو می‌شود
  (سریع‌تر، بدون وابستگی به اینترنت، مناسب سرورهای داخل ایران).
* در غیر این صورت، به CDN عمومی ارجاع داده می‌شود.

وضعیت فعلی را می‌توانید ببینید:

```bash
curl -s http://127.0.0.1:8000/api/fonts | python3 -m json.tool
```

## نصب محلی فونت (پیشنهادی)

کافی است فایل `woff2` را با همین نام‌ها در این پوشه بگذارید:

```
ui/fonts/vazir.woff2
ui/fonts/yekan.woff2
ui/fonts/shabnam.woff2
ui/fonts/sahel.woff2
ui/fonts/samim.woff2
```

مثلاً برای وزیر:

```bash
cd python-scraper4/ui/fonts
curl -fL -o vazir.woff2 \
  https://cdn.jsdelivr.net/gh/rastikerdar/vazir-font@v30.1.0/dist/Vazir-Regular.woff2
```

بعد از افزودن فایل، نیازی به ری‌استارت نیست؛ فقط صفحه را تازه کنید.

> اگر سرور به اینترنت دسترسی ندارد و فایل محلی هم نگذاشته باشید، مرورگر به
> Tahoma برمی‌گردد. این حالت عمدی است و خطا محسوب نمی‌شود.
